# Cardiovascular Disease Prediction

## Project Overview
This project uses machine learning to predict the likelihood of cardiovascular disease using patient health data.

## Objectives
- Perform data preprocessing and cleaning.
- Analyze the dataset using exploratory data analysis.
- Create visualizations and a correlation matrix.
- Compare five machine learning algorithms.
- Build a model to predict cardiovascular disease.

## Algorithms Used
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors (KNN)
5. Support Vector Machine (SVM)

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Joblib

## Project Workflow
1. Load and preprocess the dataset.
2. Perform exploratory data analysis.
3. Visualize feature distributions and correlations.
4. Train and evaluate the machine learning models.
5. Compare model performance.
6. Save the selected model and test predictions.
